# Glossary

**Alpha interval** — A cubic interval represented by two endpoint values plus `alpha0` and `alpha1`.

**Barycentric coordinates** — Nonnegative coordinates summing to one that locate a point inside a simplex.

**Binary extrapolation policy** — Rule selecting the effective binary composition used inside a pair interaction polynomial when evaluating an interior multicomponent point.

**Cubic-alpha field** — The vertex-linear local field plus three pairwise alpha excess terms.

**Elementary triangle** — One smallest triangle in the regular ternary lattice.

**Kohler** — Pair-ratio-preserving projection with `t=x_j/(x_i+x_j)`.

**Kuhn simplex** — One simplex in a permutation-based decomposition of an N-dimensional hypercube; reserved for future ND work.

**Level residual** — `|f(point)-level|`.

**Muggianu** — Centered/perpendicular binary projection with `t=1/2+(x_j-x_i)/2`.

**Regularization** — Redistribution of path points by approximate arclength followed by projection back to the isolevel.

**Shared-edge consistency** — Both triangles adjacent to an edge use the same one-dimensional interval model.
